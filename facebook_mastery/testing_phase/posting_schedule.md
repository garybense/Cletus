# Facebook Persuasive Message Testing - Posting Schedule

## A/B Testing Plan

We will test each of the 3 templates across different audience segments and time slots to measure engagement.

### Testing Matrix

| Template | Audience Segment | Day | Time | Goal |
|----------|------------------|-----|------|------|
| Template 1 (Ethical Engagement Starter) | Local Community Group A | Monday | 10:00 AM | Measure comment rate |
| Template 1 (Ethical Engagement Starter) | Local Community Group B | Thursday | 2:00 PM | Measure comment rate |
| Template 2 (Community Impact Story) | Local Community Group A | Tuesday | 11:00 AM | Measure shares/reactions |
| Template 2 (Community Impact Story) | Local Community Group B | Friday | 3:00 PM | Measure shares/reactions |
| Template 3 (Collaborative Invitation) | Local Community Group A | Wednesday | 1:00 PM | Measure event interest/sign-ups |
| Template 3 (Collaborative Invitation) | Local Community Group B | Saturday | 12:00 PM | Measure event interest/sign-ups |

### Notes:
- Each template will be posted twice (to two different but similar audience segments) to control for audience variability.
- Time slots are chosen based on typical Facebook engagement peaks (weekday mornings and afternoons, weekend noon).
- Run test for one week, then analyze metrics.
- If resources allow, extend to a second week with swapped audiences to further validate.

### Metrics to Track:
- Reach
- Reactions (likes, loves, etc.)
- Comments
- Shares
- Click-through rate (if link included)
- Engagement rate (total engagements/reach)
