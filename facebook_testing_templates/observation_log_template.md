# Facebook Persuasive Message Testing: Observation Log Template

## Overview
This template is used to track and record engagement metrics for each test post during the A/B testing phase. Consistent logging enables proper analysis and optimization of persuasive message templates.

## Logging Instructions
- **Frequency**: Log observations immediately after checking post performance (recommended: 1-hour, 3-hour, 24-hour, and 72-hour marks)
- **Consistency**: Use the same time intervals for all posts to ensure comparable data
- **Completeness**: Fill in all available metrics; note if any metric is unavailable or N/A
- **Context**: Include any relevant external factors that might influence performance
