# Facebook Persuasive Message Compliance Checklist

## Pre-Post Compliance Verification

### Facebook Advertising Policies
- [ ] Content does not violate Facebook Community Standards
- [ ] No prohibited content (illegal products, discriminatory practices, etc.)
- [ ] No misleading or false claims
- [ ] No sensationalist or shock content
- [ ] Proper use of brand assets (if applicable)
- [ ] No before/after imagery that implies unrealistic results
- [ ] No personal health claims without proper substantiation
- [ ] No financial gain promises that are unrealistic
- [ ] No political content without proper authorization (if applicable)
- [ ] No infringement on intellectual property rights

### Ethical Guidelines for Persuasive Messaging
- [ ] All claims are truthful and verifiable
- [ ] No exploitation of vulnerabilities or insecurities
- [ ] No fake scarcity or urgency tactics ("Only 3 left!" when false)
- [ ] No bait-and-switch techniques
- [ ] Respect for audience intelligence and autonomy
- [ ] Clear distinction between facts and opinions
- [ ] No manipulation through fear or guilt without constructive resolution
- [ ] Transparency about commercial intent
- [ ] No false testimonials or endorsements
- [ ] Respect for cultural sensitivities and diversity

### Automated Data Collection Terms Compliance
- [ ] No collection of personal data without explicit consent
- [ ] Clear disclosure if any data collection occurs (pixels, cookies, etc.)
- [ ] Compliance with Facebook's data use policies
- [ ] No scraping or automated collection of user data from Facebook
- [ ] Proper handling of any user-generated content (comments, messages)
- [ ] Respect for user privacy settings and preferences
- [ ] No use of collected data for purposes beyond disclosed intent
- [ ] Data security measures in place if collecting any information

### Transparency Requirements
- [ ] Clear identification as sponsored/commercial content (if applicable)
- [ ] Disclosure of any material connections, relationships, or payments that might influence the message
- [ ] Honest representation of product/service capabilities
- [ ] Clear terms and conditions for any offers
- [ ] Accessible privacy policy link (if collecting data)
- [ ] Contact information for questions or concerns
- [ ] Clear refund/return policy if applicable

### Targeting Compliance
- [ ] No discriminatory targeting based on protected characteristics
- [ ] No targeting of vulnerable audiences with inappropriate content
- [ ] Age-appropriate targeting and content
- [ ] No exclusion based on protected characteristics without legitimate reason
- [ ] Compliance with special ad category requirements (if applicable)

### Post-Post Monitoring
- [ ] Monitor comments for compliance issues
- [ ] Address any misleading claims made in comments
- [ ] Report and remove any inappropriate user-generated content
- [ ] Track and document any compliance concerns raised by audience
- [ ] Adjust future posts based on compliance learnings

## Template-Specific Compliance Checks

### Template 1: Social Proof
- [ ] Verify all user testimonials are genuine and authorized
- [ ] Ensure no exaggeration of user numbers or results
- [ ] Clear that results may vary based on individual circumstances
- [ ] No implication that everyone will get the same results

### Template 2: Transformation/Benefit-Focused
- [ ] No unrealistic transformation claims
- [ ] Clear timeline expectations (no "overnight success" promises)
- [ ] Acknowledge that effort is required from the user
- [ ] No before/after imagery that could be misleading
- [ ] Disclose if results are not typical

### Template 3: Problem-Agitate-Solve
- [ ] Acknowledge problem exists without exploiting emotions
- [ ] Ensure proposed solution genuinely addresses stated problem
- [ ] No false dilemma presentation (only our solution works)
- [ ] Acknowledge alternative approaches exist
- [ ] No exaggeration of problem severity without basis

## Approval Process
- [ ] Self-check completed using this checklist
- [ ] Peer review recommended for high-reach posts
- [ ] Legal/compliance review for regulated industries
- [ ] Final approval documented before posting
- [ ] Post-publication review scheduled

## Violation Response Plan
- [ ] Process for immediately removing non-compliant content
- [ ] Procedure for addressing user complaints
- [ ] Documentation of compliance incidents and resolutions
- [ ] Plan for preventing recurrence of similar issues
- [ ] Escalation path for serious compliance violations
