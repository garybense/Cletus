# Persuasive Message Template: Scarcity & Urgency Approach

## Template Overview
This template uses principled scarcity and urgency to motivate action while maintaining ethical standards.

## Message Template
```
⏰ [Time-bound opportunity] ending soon!

[Specific offer] is available for [limited time/quantity] only.
Don't miss out on [key benefit] that [specific audience] are using to [desired outcome].

🔥 What you'll get:
• [Benefit 1]
• [Benefit 2] 
• [Benefit 3]

⚠️ Only [X] spots left / Ends [specific date/time]

👉 Secure your access now: [Link]

#[Relevant hashtag 1] #[Relevant hashtag 2] #[Urgency hashtag]
```

## Customization Guidelines
- Replace `[Time-bound opportunity]` with specific, truthful time limitation (e.g., "48-hour flash sale", "Weekend workshop")
- `[Specific offer]` should be concrete and valuable
- `[Limited time/quantity]` must be accurate and verifiable
- Benefits should be specific and audience-relevant
- Use real countdowns when possible (e.g., "Ends Friday at 5 PM EST")
- For limited quantity, state actual available spots
- Link must lead to a working, relevant landing page
- Use urgency hashtags sparingly (e.g., #LimitedTime, #OfferEndsSoon)

## Ethical Considerations
- Scarcity claims must be truthful and verifiable
- Never create artificial scarcity (don't claim limited spots when unlimited)
- Clearly state exact end time/date including timezone
- If extending an offer, communicate clearly to avoid misleading
- Avoid pressure tactics that exploit FOMO unethically
- Comply with Facebook's prohibition on misleading claims

## A/B Testing Variables
- Test different time frames (24h vs 48h vs 1 week)
- Experiment with benefit highlighting (lead with different benefits)
- Test different scarcity mechanisms (time vs quantity)
- Vary the specificity of the deadline (exact time vs "ending soon")
