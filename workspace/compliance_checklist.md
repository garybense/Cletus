# Facebook Persuasive Message Compliance Checklist
## Ensuring Adherence to Facebook's Automated Data Collection Terms and Ethical Standards

## Pre-Posting Review Checklist
Complete this checklist before publishing any persuasive message on Facebook.

### 1. Content Authenticity & Transparency
- [ ] All claims are truthful and verifiable
- [ ] No exaggeration of results, benefits, or effectiveness
- [ ] Clear identification of sender/organization
- [ ] Disclosure of any affiliations, sponsorships, or partnerships
- [ ] No impersonation of other individuals or entities
- [ ] Clear distinction between opinion and factual statements

### 2. Ethical Persuasion Standards
- [ ] No manipulation through fear, guilt, or false urgency
- [ ] No exploitation of vulnerabilities (financial, emotional, health-related)
- [ ] Respect for user autonomy and right to disengage
- [ ] No pressure tactics or artificial scarcity ("limited time!" unless genuinely true)
- [ ] Provides genuine value regardless of user response
- [ ] Acknowledges limitations of advice/products/services

### 3. Facebook Policy Compliance
- [ ] Complies with Facebook Community Standards
- [ ] No prohibited content (hate speech, harassment, violence, etc.)
- [ ] No misleading or deceptive content
- [ ] Proper use of Facebook features (no misuse of tags, shares, etc.)
- [ ] No circumvention of Facebook's systems or algorithms
- [ ] Compliance with Advertising Policies if applicable (even for organic posts)

### 4. Data Collection & Privacy Compliance
- [ ] No collection of personal data without explicit consent
- [ ] Clear explanation if any data is being collected (even implicitly through engagement)
- [ ] No use of automated tools to scrape or harvest user data
- [ ] Respect for user privacy settings and preferences
- [ ] No tracking or monitoring beyond standard Facebook insights
- [ ] Clear opt-out mechanism for any data usage

### 5. Audience Appropriateness
- [ ] Content suitable for intended audience age/demographics
- [ ] No targeting of vulnerable populations without appropriate safeguards
- [ ] Content warnings if discussing sensitive topics
- [ ] Respect for cultural, religious, and social sensitivities
- [ ] No discriminatory language or implications

### 6. Value Exchange Balance
- [ ] Clear value provided to user (information, entertainment, community, etc.)
- [ ] Request/ask is proportional to value given
- [ ] No bait-and-switch tactics
- [ ] Transparency about any future requests or upsells
- [ ] User can benefit without providing anything in return

### 7. Evidence & Substantiation
- [ ] Any statistical claims are properly sourced
- [ ] Testimonials are genuine and not misleading
- [ ] Before/after claims are realistic and typical results disclosed
- [ ] Scientific claims reference credible sources
- [ ] No cherry-picking of data to support claims

### 8. Engagement Ethics
- [ ] Encourages authentic, meaningful engagement
- [ ] No incentivizing fake engagement (likes, shares, comments)
- [ ] Respectful handling of dissenting opinions or criticism
- [ ] No creation of false consensus or bandwagon effects
- [ ] Encourages critical thinking and informed decisions

### 9. Post-Posting Responsibilities
- [ ] Monitor comments for harmful content or misinformation
- [ ] Respond to questions and concerns in timely manner
- [ ] Correct any misinformation that arises in comments
- [ ] Respect user requests to stop communication
- [ ] Document engagement metrics for ethical review

### 10. Record Keeping
- [ ] Save copy of original post
- [ ] Document targeting criteria (if using Facebook ads/tools)
- [ ] Record engagement metrics and audience feedback
- [ ] Note any compliance issues or user complaints
- [ ] Maintain for platform audit requirements

## Special Considerations for Persuasive Message Templates

### For Educational Value Approach:
- [ ] Educational content is accurate and up-to-date
- [ ] Clear distinction between established facts and personal opinion
- [ ] No presentation of hypothesis as proven fact
- [ ] Resources shared are genuinely helpful and accessible

### For Social Proof & Community Building:
- [ ] Social proof is genuine and not manufactured
- [ ] Community benefits are real and not exaggerated
- [ ] No creation of artificial peer pressure
- [ ] Inclusive language that welcomes diverse perspectives

### For Problem-Agitation-Solution (Ethical PAS):
- [ ] Problem description is accurate and not exaggerated
- [ ] Solution offered is appropriate scope for the problem
- [ ] Clear boundaries on what advice can/cannot provide
- [ ] Encourages professional consultation when appropriate
- [ ] No claims to solve complex issues with simple fixes

## Quick Reference: Red Flags to Abort Posting
STOP and review if you see:
- ❌ "Limited time offer!" without genuine scarcity
- ❌ Guarantees of specific results (especially financial/health)
- ❌ Pressure to act immediately without consideration
- ❌ Claims that seem "too good to be true"
- ❌ Targeting specific vulnerabilities (debt, illness, loneliness)
- ❌ Requests for personal information beyond what's necessary
- ❌ Disguised ads as organic content without disclosure
- ❌ Content that makes users feel inadequate or fearful
