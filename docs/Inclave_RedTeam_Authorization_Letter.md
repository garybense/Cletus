## 3. RULES OF ENGAGEMENT (ROE) & BOUNDARIES

1. **Authorized Testing Activities**:
   - Web application security assessments (OWASP Top 10 evaluation).
   - API security auditing and authentication flow verification.
   - Network vulnerability scanning and configuration review.

2. **Prohibited / Out-of-Scope Activities**:
   - Denial of Service (DoS / DDoS) attacks or intentional service disruption.
   - Physical security breaches or physical facility intrusions.
   - Unsolicited social engineering or spear-phishing against non-participating personnel.
   - Destruction, deletion, or exfiltration of production customer data.

3. **Emergency Contact & Halt Procedure**:
   - If an unexpected system degradation or critical security flaw is identified, testing must pause immediately, and the Incident Response Team must be notified via designated escalation channels.
