## 2026-09-08 - Batching Inter-Agent Inbox Updates & Automated Child Process Reaping / **Learning:** Individual SQLite UPDATE transactions per inbox message during inter-agent message processing introduced high write latency per heartbeat turn. Additionally, un-reaped dead/failed child processes accumulated without automated cleanup. / **Action:** Batched inbox status updates into single transaction passes in ColonyMessaging.processInbox and implemented automated child process/sandbox reaping via ChildMonitor.reapStaleChildren.

## 2026-09-09 - Dual Scheduler Compatibility & Active Goal Filtering / **Learning:** DurableScheduler constructor signature mismatch broke heartbeat test execution when called with legacy parameters. Additionally, getReadyTasks queried pending tasks across all goals without filtering by active goals, allowing stale/failed goals to block scheduling. / **Action:** Refactored DurableScheduler to support both worker-id and legacy DB/task-map constructor signatures, executing both Phase 1.1 heartbeat schedules and Phase 1 queue work. Updated getReadyTasks to join the goals table and filter by active goals.
